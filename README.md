# Hero редизайн — Apple-style з фото G2 Pro

## Що зроблено

Hero на головній сторінці тепер має фото G2 Pro **праворуч** від тексту,
з м'яким **оранжевим світінням** позаду та **маскою-розтанення** по краях
— фото зливається з фоном, не виглядає як вирізана картинка.

Естетика: Apple, Tesla, преміум.

## Файли в пакеті

```
public/hero/g2-pro.png                       ← НОВИЙ (фото 60 KB)
components/kukirin/KukirinHero.tsx           ← замінити
```

## Як працює

1. **Фото** лежить у `public/hero/g2-pro.png` — Next.js віддає з URL `/hero/g2-pro.png`
2. **Soft glow** — два накладені `radial-gradient` (оранжевий і світло-оранжевий) з `blur(40px)`. Створюють "ауру" за самокатом
3. **Маска фото** — `mask-image: radial-gradient(ellipse 85% 90% at center, black 60%, transparent 95%)`. Це робить так, що **краї фото плавно зливаються з фоном**, а не мають різкої межі
4. **Drop-shadow оранжевим** під фото — додаткова "тепла" підсвітка

## Якщо фото не зайде вибором ракурсу/обрізки

Перезавантаж фото у `public/hero/g2-pro.png` через GitHub з іншим
ракурсом (бічний вид, як на сторінці катало­гу) — нічого міняти в коді
не треба, шлях той самий.

## Якщо хочеш ще міцніше світіння або зовсім без нього

В `KukirinHero.tsx` знайди рядки з `radial-gradient`:
- Більше світіння: `rgba(255,107,0,0.32)` → `rgba(255,107,0,0.55)`
- Менше: → `rgba(255,107,0,0.15)`
- Зовсім без: видали обидва div-и з `radial-gradient`

Маску теж можна послабити — `ellipse 85% 90%` → `ellipse 100% 100%`
(тоді жодного fade на краях).
