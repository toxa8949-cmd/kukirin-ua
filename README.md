# Картки товара — повний редизайн

## Що змінилось

### Каталог (`app/catalog/page.tsx`)
- **Контейнер фото:** `aspect-[4/3]` → `aspect-square` (1:1 як Apple, Amazon)
- **Фон:** градієнт бежевий/сірий → **чистий білий** (фокус на товар)
- **Padding:** `p-4` → `p-8` (фото "дихає")
- **Бордюр:** від картки відокремлено фото горизонтальною лінією знизу
- **Бейдж:** з правого кута → **лівий верхній кут** (нативніше для e-commerce)
- **Hover:** додано `shadow-md` — картка піднімається при наведенні
- **Радіус:** `rounded-sm` → `rounded-md` (м'якше)
- **Gap між картками:** `gap-5` → `gap-6`

### Картка товара (`app/product/[slug]/page.tsx`)
- **Фон:** темний градієнт `#1a1a1a→#0a0a0a` → **білий** (це була регресія від мого автоматичного перетворення — забув додати `dark:` префікс)
- **Padding:** `p-6` → `p-10`
- **Бейдж "KUKIRIN · 2026":** додано `bg-white/80 + backdrop-blur` щоб був читабельний на світлому
- **Радіус:** `rounded-md`

## Як працюватиме у темній темі

Все так само як зараз:
- Темний градієнт повертається завдяки `dark:bg-gradient-to-br dark:from-[#1a1a1a]`
- Бейджі мають свої `dark:` варіанти
