# Hero — Tech Sheet (D варіант)

## Що зроблено

Фото G2 Pro тепер у **технічному паспорті** — біла картка з тонкою сіткою,
оранжеві лінії-вимірники, координати, тег "FLAGSHIP". Cyberpunk-вайб, як на
блюпринтах техніки.

## Деталі дизайну

- **Квадратна біла картка** з тонкою рамкою `#E8E6DE`
- **Сітка 24×24px** як фоновий blueprint
- **Вимірники по периметру:**
  - Вертикальна лінія зліва: `H: 1156mm`
  - Горизонтальна знизу: `L: 1206mm`
- **Координати** у правому верхньому: `XY: 0.61 · 1.18`
- **Тег** у лівому верхньому: `// 01 · FLAGSHIP`
- **Фото з multiply** — білий фон фото зливається з білою карткою (жодних швів!)
- **М'яке оранжеве світіння** під самокатом
- **Підпис** під карткою: `// FLAGSHIP · 600W · 45 KM/H  ·  G2 PRO · 2026`

## У темній темі

Картка темна (`#0A0A0A`), сітка трохи світліша, фото інвертується (`dark:invert`).
Усе автоматично через `dark:` класи.

## Як підкрутити (якщо треба)

Усі параметри у файлі `KukirinHero.tsx` — секція `<!-- ПРАВА: Tech Sheet з фото -->`:

- **Розмір сітки:** `backgroundSize: '24px 24px'` → можна 16/32/40
- **Колір сітки:** `rgba(232,230,222,0.5)` → темніше/світліше
- **Інтенсивність світіння під самокатом:** `rgba(255,107,0,0.10)` → 0.15/0.20
- **Padding фото:** `p-12` → `p-10` (більше фото) або `p-16` (більше повітря)

## Чого очікувати

- ✅ Самокат **природньо лежить** на білій картці — жодних швів через multiply
- ✅ Виглядає як технічний паспорт продукту
- ✅ Грайворитися з KUKIRIN-вайбом (sys.boot, координати, виміри)
- ✅ Працює в темній темі (через `dark:` класи)

Якщо на реальному сайті щось виглядає не так — скрін, дамо точкове рішення.
