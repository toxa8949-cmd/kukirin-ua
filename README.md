# Hero — фото з вирізаним фоном (нарешті 🙂)

## Що зроблено

Сам **вирізав білий фон** з фото G2 Pro. PNG тепер має прозорий канал —
самокат "плаває" на бежевому/чорному фоні без прямокутної рамки.

Зробив через Python:
- Завантажив твоє фото
- Знайшов що фон чисто білий (255,255,255 у всіх кутах)
- Для кожного пікселя обчислив **яскравість** і **насиченість**
- Білі + ненасичені пікселі → повністю прозорі
- Світло-сірі по краях → плавний градієнт прозорості (anti-aliasing)
- Все що темне або кольорове (метал, оранжеві акценти) → лишилось

Результат: 88% пікселів стали прозорими, 11% — самокат, 3225 пікселів — м'які краї.
