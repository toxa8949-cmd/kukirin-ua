# Фікс — фото товарів обрізаються

## Що було

`object-cover` обрізав фото товарів щоб вони заповнили контейнер
(співвідношення 4:3 в каталозі, ще одне на картці товара).
Реальні фото KUKIRIN — широкі ~16:9, тому з боків зрізались
колеса і крила.

## Що зроблено

Замінив `object-cover` → `object-contain` + додав padding (`p-4` в
каталозі, `p-6` на картці товара). Тепер фото:
- Вписується у контейнер **цілком**, нічого не обрізається
- Має невелике поле навколо (як на kukirin.com.ua)
- При наведенні все ще збільшується (`scale-105`)

## Файли
