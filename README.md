# Швидкий фікс — обводку прибрано

## Що зроблено

Прибрав помаранчеву обводку. Hero повертається до **м'якого варіанту**:
- Фото G2 Pro (оригінал, з білим фоном)
- `mix-blend-multiply` щоб білий фон "втопився" у бежевий
- М'яке оранжеве світіння за самокатом
- Drop-shadow помаранчевим тоном

Це той стан що був до обводки. Не ідеально (можуть лишитись світлі краї
на світлій темі), але **не страх і ужас**.

## Що в пакеті

```
public/hero/g2-pro.png               ← оригінальне фото (60 KB)
components/kukirin/KukirinHero.tsx   ← Hero без обводки
```

## Як залити

1. Розпакуй ZIP
2. GitHub → Upload files → перетягни папку `public/` → замінити так
3. Окремо заміни `components/kukirin/KukirinHero.tsx`
4. Commit: `revert: remove orange stroke, keep soft glow`
