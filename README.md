# Hero — помаранчева обводка по силуету G2 Pro

## Що зроблено

Самокат тепер обведений 3-піксельною **помаранчевою лінією** по контуру
свого силуету. Плюс легке зовнішнє свічення (м'який ореол).

Виглядає як: брендовий нео-style, "outlined product", дуже впізнавано.

## Як це працює технічно

Через CSS `filter: drop-shadow()` — 8 копій тіні з нульовим радіусом
розмиття у 8 напрямках (`3px 0`, `-3px 0`, `0 3px`, `0 -3px`,
`2px 2px`, тощо). Це наповнює альфа-канал PNG помаранчевим у 3px
радіусі від силуету — реальна обводка, не картинка.

Плюс 9-та drop-shadow `(0 0 20px rgba(255,107,0,0.4))` — м'який
ореол свічення.

**Бонус:** обводка автоматично ховає той fringe (білі залишки навколо
темних деталей), який раніше виглядав погано.

## Як підкрутити якщо щось не так

У файлі `KukirinHero.tsx` зверху є масив `orangeStroke`:

```js
const orangeStroke = [
  'drop-shadow(3px 0 0 #FF6B00)',     // ← товщина (3 → 2/4)
  'drop-shadow(-3px 0 0 #FF6B00)',
  // ... ще 6 напрямків
  'drop-shadow(0 0 20px rgba(255,107,0,0.4))',  // ← інтенсивність свічення
].join(' ');
```

- **Тонше:** заміни `3px` → `2px` (8 разів)
- **Товще:** `3px` → `4px`
- **Без свічення:** видали останній рядок
- **Інший колір:** заміни `#FF6B00` на потрібний (наприклад `#FFFFFF` для білого)

## Якщо стане видно артефакти на тонких деталях (троси, ручки)

drop-shadow в 8 напрямках може створювати "залипання" обводки на тонких деталях.
Якщо помітиш — скинь скрін, переведу на 4 напрямки (грубіше, але стабільніше).
