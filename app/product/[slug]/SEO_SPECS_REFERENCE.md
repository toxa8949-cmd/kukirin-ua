# Розширений Product schema — як заповнити поля в специфікаціях

Ця сторінка тепер читає **додаткові SEO-поля з products.specs (jsonb)**.
Усі поля **опціональні** — якщо їх немає, сторінка просто пропускає відповідні
блоки. Старі товари без цих полів продовжують працювати.

## Мінімум для топу в Google (рекомендую)

1. **`long_description`** — 500+ символів унікального тексту для кожної моделі.
   Google ранжує сторінки з більшим вмістом вище. **Не копіюй з сайту виробника!**
2. **`faq`** — 5+ питань. Google показує їх прямо в результатах пошуку.
3. **`video_url`** — YouTube огляд. Дає окрему рич-карточку у видачі.
4. **`weight`, `dimensions`, `load_capacity`, `warranty`** — Google використовує
   це як `additionalProperty` у Product schema.

## Як перевірити після заповнення

1. Залий ZIP, дочекайся deploy.
2. Відкрий `https://kukirinstore.com.ua/product/<твій-slug>`.
3. Перевір що з'явились блоки: "ДЕТАЛЬНИЙ ОГЛЯД", "ХАРАКТЕРИСТИКИ", "ВІДЕО-ОГЛЯД", "ПИТАННЯ ПОКУПЦІВ".
4. Прогони сторінку через Rich Results Test:
   - Має знайти: **Product** + **BreadcrumbList** + **FAQPage** + **VideoObject**.
